# Privacy

LegacySift is designed as a local-only desktop utility.

## Data processed

LegacySift reads only the local folders and files selected by the user for comparison. Depending on the action explicitly chosen by the user, it may write local reports, create a local safety folder, move exact duplicate files out of the OLD folder, restore files from that safety folder, or send exact duplicates from the OLD folder to the Windows Recycle Bin.

## Network behavior

LegacySift does not require an online account, does not include telemetry or analytics, and does not upload the user's files or comparison results.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Downloads from GitHub, code-signing infrastructure, web pages and any future update mechanism are outside the normal local comparison operation unless the user explicitly initiates them.

## Current-folder protection

The CURRENT folder is used as the protected comparison reference. LegacySift's cleanup workflow is designed so that cleanup modifies only the OLD folder side.

## Questions

Privacy and security questions can be raised through the public LegacySift GitHub repository.
